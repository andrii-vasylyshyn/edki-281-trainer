# Тренажер ЄДКІ 281

Тренажер для підготовки до ЄДКІ зі спеціальності 281 «Публічне управління та адміністрування».

- 21 офіційний зразок завдань ЄДКІ
- 709 тестів НАДС із законодавства: Конституція, «Про державну службу», «Про запобігання корупції», спеціальне законодавство
- відповіді за офіційним ключем, пояснення з посиланням на статті закону
- позначка «Закон змінився», якщо ключ 2018 року розходиться з чинною редакцією
